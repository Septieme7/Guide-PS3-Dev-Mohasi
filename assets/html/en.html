01

Complete Guide: mohasi's PS3 Dev Tools

This guide presents all the PS3 homebrew tools developed by mohasi, available on the GitHub repository mohasi/ps3-dev. These applications cover PC streaming, file management, downloading, thermal monitoring, customization, and much more.

ℹ️

Important: All these tools are free and open-source homebrews, designed to work on PS3 CFW and HEN. Some tools are PS3 applications (.pkg), others are plugins to inject into the XMB.

🔄

Update: The repository is actively maintained. Releases are identified by a version number (e.g., 191-3541f8d). Check the releases page regularly for the latest versions.

02

Essential Prerequisites

Before installing these tools, make sure you have:

  • A modified PS3: CFW (Evilnat, Rebug, etc.) or PS3HEN enabled.
  • A Windows PC (for PC tools like Theme Studio and RCO Studio).
  • A network connection between the PC and PS3 (for FTP and streaming).
  • A USB drive formatted in FAT32 (for transferring PKGs).
⚠️

HEN Reminder: On PS3HEN, you must enable HEN before each session. Without it, homebrews will not launch.

03

Installing the Tools

All PS3 applications from mohasi are distributed as .pkg files. Installation is the same as any PKG.

Method 1: Via USB Drive

  1. Download the .pkg file from the releases page.
  2. Copy the .pkg file into a folder named PKG at the root of your USB drive.
  3. Insert the USB drive into the PS3.
  4. On the XMB, go to Game > Package Manager > Install Package Files.
  5. Select USB Storage Device, then the .pkg file.
  6. Press X to install.

Method 2: Via FTP

  1. Connect to your PS3 via FileZilla (see the FTP section in related guides).
  2. Transfer the .pkg file to /dev_hdd0/packages/.
  3. On the XMB, go to Game > Package Manager > Install Package Files.
  4. Select System Storage, then the .pkg file.
💡

Tip: Some tools, like Simple Disc Mount and Simple Cheat Menu, are plugins. They require additional configuration (injection into boot_plugins.txt or launching via webMAN). Check each tool's README for details.

04

Main Applications

🎮 Cell Stream — PC to PS3 Streaming

Cell Stream streams your Windows PC's screen and sound to the PS3 in real time, and turns the PS3 controller into an input device for the PC. Ideal for playing your PC games from the couch.

  • Low latency: about 25 ms at 720p60 over Wi-Fi.
  • Xbox Cloud mode: launch Xbox Cloud games directly from the PS3.
  • PS3 controller: works as an Xbox pad, with analog triggers (L2/R2).

Link: Cell Stream — Releases

📁 File Manager — File Browser

File Manager is a modern file browser for PS3, with a flat, themeable UI. It allows you to navigate PS3 partitions, copy, move, rename, and delete files.

  • ISO mounting: press X on an .iso file to mount it as a Blu-ray disc.
  • Google Drive: Google Drive appears as a folder, with download, upload, rename, and delete options.
  • Disc dump: sector-by-sector dump to /dev_hdd0/dumps.
  • Properties panel: shows name, type, size, permissions, SHA-1, etc.

Link: File Manager — Releases

🎥 Yo! Player — Native YouTube Client

Yo! Player is a native YouTube client for PS3. It allows you to browse feeds, search videos, open channels, and play up to 1080p with sound — all without PSN and without ads.

  • No PSN: no PlayStation Network connection required.
  • No ads: direct video playback.
  • 1080p: maximum supported quality.
  • Downloads: downloaded videos are saved as MP4 in the XMB's Video column.

Link: Yo! Player — Releases

🌡️ Thermal Bench — Thermal Test Tool

Thermal Bench is a thermal test tool that tells you if your PS3 runs too hot, and whether a repaste, fan change, or overclock made a difference.

  • Live readouts: CPU/GPU temperatures, fan speed, RSX clocks.
  • Graph: history of the last 2 to 30 minutes.
  • 4 load steps: from off to full burn (CPU, SPU, GPU).
  • Saves: each test is saved to /dev_hdd0/tmp/thermal-bench/.
  • Live overclocking: change RSX clocks without rebooting.

Link: Thermal Bench — Releases

🧲 Swarm — Torrent Client with VPN

Swarm is a torrent client for PS3 that lets you search and download torrents directly to the console's hard drive, with no PC involved. It supports a VPN.

  • Built-in search: Torrents-CSV and The Pirate Bay configured by default.
  • WireGuard VPN: copy your .conf file to /dev_hdd0/tmp/swarm/wireguard.conf.
  • Kill switch: blocks all network traffic if the VPN is down.
  • Resilient download: automatically resumes where it left off.
  • Privacy: the log never names what you downloaded.

Link: Swarm — Releases

🎨 Ren'Py Player — Visual Novel Player

Ren'Py Player is a visual novel player for PS3. It plays .rpk files generated from PC Ren'Py games.

  • Format: .rpk files to be placed in /dev_hdd0/renpy.
  • Conversion: use the renpy-to-ps3.exe tool on PC to create .rpk files.
  • Compatibility: works on PS3 and RPCS3.

Link: Ren'Py Player — Releases

05

Plugins

💿 Simple Disc Mount — ISO Mounting

Simple Disc Mount is a VSH plugin that adds a "Mount Disc Image" submenu to the XMB Games column. It lists all .iso files in /dev_hdd0/PS3ISO and allows mounting them as Blu-ray discs.

  • Quick access: mount your ISOs directly from the XMB.
  • Disc insertion: inserting a real disc automatically unmounts the mounted ISO.

Link: Simple Disc Mount — Releases

📡 Simple FTP — Anonymous FTP Server

Simple FTP is a plugin that provides an anonymous FTP server on port 21. It allows transferring files to and from the PS3 via FTP.

  • Anonymous: no authentication required.
  • Binary only: binary transfers to avoid corruption.
  • Built-in: included in File Manager.

Link: Simple FTP — Releases

🎵 Simple CD Info — Audio CD Info

Simple CD Info is a plugin that restores track, album, and artist names for audio CDs in the XMB. It queries the gnudb database.

  • Automatic lookup: no configuration required.
  • Genre and disc number: correctly fills metadata.
  • HEN and CFW compatible.

Link: Simple CD Info — Releases

🎮 Simple Cheat Menu — In-Game Cheat Menu

Simple Cheat Menu is a plugin that adds an in-game cheat menu. Briefly press the PS button during any game to open the menu and toggle cheats live.

  • No PC: nothing to configure per game.
  • Artemis database: cheats are pulled from the Artemis database.
  • Patches tab: replace textures in-game (with Patch Studio).
  • Stats counter: displays framerate, clocks, and temperatures.

Link: Simple Cheat Menu — Releases

🔗 Simple Debug Bridge — Remote Debugging

Simple Debug Bridge is a plugin that allows remote debugging and control of the PS3 over TCP (port 8785). It comes with a Windows client (debug-bridge-client.exe).

  • Remote control: press buttons, launch and quit titles.
  • Local HTTP proxy: http://localhost:8786 for deployment tools.
  • Logs: view console logs.

Link: Simple Debug Bridge — Releases

06

PC Tools (Windows)

🎨 Theme Studio — PS3 Theme Editor

Theme Studio is a PS3 theme editor for Windows. It allows creating 2D themes and true dynamic 3D themes with models, motion, and lighting — features Sony's own tools never supported.

  • 2D themes: custom backgrounds, icons, cursors, and menu sounds.
  • 3D themes: models, motion, and lighting.
  • PSJS script: write scene motion in Sony's script language.
  • Live preview: script is played back as you type.
  • Export: one click to build the .p3t file or deploy to the console over the network.

Link: Theme Studio — Releases

🖼️ RCO Studio — XMB Resource Editor

RCO Studio is a modern tool for editing PS3 XMB resource files (RCOs). It replaces the old RCOmage workflow.

  • Drag and drop: no typing paths or naming files.
  • FTP deploy: upload compiled RCOs to dev_blind.
  • Undo: right-click to undo all changes in an RCO at once.
  • Properties panel: shows details of the selected file.

Link: RCO Studio — Releases

🖌️ Patch Studio — Texture Replacement

Patch Studio is a PC tool that allows replacing any texture in any PS3 game, with no game-specific work needed.

  • Dump: on the cheat menu's Patches tab, Square dumps the running game's textures.
  • Edit: Patch Studio downloads the dumps, turns them into editable images.
  • Apply: sends the patch back to the console and applies it in-game.

Link: Patch Studio — Releases

Troubleshooting

Common Issues

IssueLikely CauseSolution
App won't launch HEN not enabled (on PS3HEN). Enable HEN before launching the app.
Cell Stream: high latency Unstable Wi-Fi connection. Use a wired connection (Ethernet) between PC and PS3.
Yo! Player: videos stuck at 1 minute Google changed its API. Update Yo! Player to the latest version (Apple Vision Pro client is not capped).
Simple Disc Mount: ISO not listed ISO is not in the correct folder. Place your ISOs in /dev_hdd0/PS3ISO/.
Simple Cheat Menu: cheats not found Missing Artemis database or unsupported game. Check that the game is in the Artemis database.
