01

Guide complet : Les outils PS3 Dev de mohasi

Ce guide vous présente l'ensemble des outils homebrew PS3 développés par mohasi, disponibles sur le dépôt GitHub mohasi/ps3-dev. Ces applications couvrent le streaming PC, la gestion de fichiers, le téléchargement, la surveillance thermique, la personnalisation et bien plus encore.

ℹ️

Important : Tous ces outils sont des homebrews gratuits et open-source, conçus pour fonctionner sur PS3 CFW et HEN. Certains outils sont des applications PS3 (.pkg), d'autres sont des plugins à injecter dans le XMB.

🔄

Mise à jour : Le dépôt est activement maintenu. Les releases sont identifiées par un numéro de version (ex: 191-3541f8d). Consultez régulièrement la page des releases pour les dernières versions.

02

Prérequis essentiels

Avant d'installer ces outils, assurez-vous de disposer de :

  • Une PS3 modifiée : CFW (Evilnat, Rebug, etc.) ou PS3HEN activé.
  • Un PC sous Windows (pour les outils PC comme Theme Studio et RCO Studio).
  • Une connexion réseau entre le PC et la PS3 (pour le FTP et le streaming).
  • Une clé USB formatée en FAT32 (pour le transfert des PKG).
⚠️

Rappel HEN : Sur PS3HEN, vous devez activer HEN avant chaque session. Sans cela, les homebrews ne se lanceront pas.

03

Installation des outils

Toutes les applications PS3 de mohasi sont distribuées au format .pkg. L'installation est identique à celle de n'importe quel PKG.

Méthode 1 : Via clé USB

  1. Téléchargez le fichier .pkg depuis la page des releases.
  2. Copiez le fichier .pkg dans un dossier nommé PKG à la racine de votre clé USB.
  3. Insérez la clé USB dans la PS3.
  4. Sur le XMB, allez dans Jeu > Gestionnaire de paquets > Installer les fichiers PKG.
  5. Sélectionnez Support USB, puis le fichier .pkg.
  6. Appuyez sur X pour installer.

Méthode 2 : Via FTP

  1. Connectez-vous à votre PS3 via FileZilla (voir la section FTP dans les guides connexes).
  2. Transférez le fichier .pkg dans /dev_hdd0/packages/.
  3. Sur le XMB, allez dans Jeu > Gestionnaire de paquets > Installer les fichiers PKG.
  4. Sélectionnez Stockage système, puis le fichier .pkg.
💡

Astuce : Certains outils, comme Simple Disc Mount et Simple Cheat Menu, sont des plugins. Ils nécessitent une configuration supplémentaire (injection dans boot_plugins.txt ou lancement via webMAN). Consultez le README de chaque outil pour plus de détails.

04

Applications principales

🎮 Cell Stream — Streaming PC vers PS3

Cell Stream diffuse l'écran et le son de votre PC Windows vers la PS3 en temps réel, et transforme la manette PS3 en périphérique d'entrée pour le PC. Idéal pour jouer à vos jeux PC depuis votre canapé.

  • Latence faible : environ 25 ms en 720p60 sur Wi-Fi.
  • Mode Xbox Cloud : lancez directement des jeux Xbox Cloud depuis la PS3.
  • Manette PS3 : fonctionne comme une manette Xbox, avec gâchettes analogiques (L2/R2).

Lien : Cell Stream — Releases

📁 File Manager — Gestionnaire de fichiers

File Manager est un navigateur de fichiers moderne pour PS3, avec une interface plate et thémable. Il permet de naviguer dans les partitions de la PS3, de copier, déplacer, renommer et supprimer des fichiers.

  • Montage d'ISO : appuyez sur X sur un fichier .iso pour le monter en tant que disque Blu-ray.
  • Google Drive : Google Drive apparaît comme un dossier, avec possibilité de télécharger, uploader, renommer et supprimer.
  • Dump de disque : dump secteur par secteur vers /dev_hdd0/dumps.
  • Panneau de propriétés : affiche le nom, type, taille, permissions, SHA-1, etc.

Lien : File Manager — Releases

🎥 Yo! Player — Client YouTube natif

Yo! Player est un client YouTube natif pour PS3. Il permet de parcourir les flux, rechercher des vidéos, ouvrir des chaînes et lire en 1080p avec son — le tout sans PSN et sans publicité.

  • Sans PSN : aucune connexion au PlayStation Network requise.
  • Sans publicité : lecture directe des vidéos.
  • 1080p : qualité maximale supportée.
  • Téléchargements : les vidéos téléchargées sont sauvegardées en MP4 dans la colonne Vidéo du XMB.

Lien : Yo! Player — Releases

🌡️ Thermal Bench — Test thermique

Thermal Bench est un outil de test thermique qui permet de savoir si votre PS3 chauffe trop, et si un repaste, un changement de ventilateur ou un overclocking a fait une différence.

  • Relevés en direct : températures CPU/GPU, vitesse du ventilateur, fréquences RSX.
  • Graphique : historique des 2 à 30 dernières minutes.
  • 4 niveaux de charge : de l'arrêt à la charge maximale (CPU, SPU, GPU).
  • Sauvegarde : chaque test est sauvegardé dans /dev_hdd0/tmp/thermal-bench/.
  • Overclocking en direct : modifiez les fréquences RSX sans redémarrer.

Lien : Thermal Bench — Releases

🧲 Swarm — Client torrent avec VPN

Swarm est un client torrent pour PS3 qui permet de rechercher et télécharger des torrents directement sur le disque dur de la console, sans PC. Il supporte un VPN.

  • Recherche intégrée : Torrents-CSV et The Pirate Bay configurés par défaut.
  • VPN WireGuard : copiez votre fichier .conf dans /dev_hdd0/tmp/swarm/wireguard.conf.
  • Kill switch : bloque tout trafic réseau si le VPN est down.
  • Téléchargement résilient : reprend automatiquement là où il s'est arrêté.
  • Confidentialité : le journal ne nomme jamais ce que vous avez téléchargé.

Lien : Swarm — Releases

🎨 Ren'Py Player — Lecteur de visual novels

Ren'Py Player est un lecteur de visual novels pour PS3. Il lit les fichiers .rpk générés à partir de jeux Ren'Py PC.

  • Format : fichiers .rpk à placer dans /dev_hdd0/renpy.
  • Conversion : utilisez l'outil renpy-to-ps3.exe sur PC pour créer les .rpk.
  • Compatibilité : fonctionne sur PS3 et RPCS3.

Lien : Ren'Py Player — Releases

05

Plugins

💿 Simple Disc Mount — Montage d'ISO

Simple Disc Mount est un plugin VSH qui ajoute un sous-menu « Mount Disc Image » à la colonne Jeu du XMB. Il liste tous les fichiers .iso présents dans /dev_hdd0/PS3ISO et permet de les monter en tant que disque Blu-ray.

  • Accès rapide : montez vos ISOs directement depuis le XMB.
  • Insertion de disque : insérer un vrai disque démonte automatiquement l'ISO montée.

Lien : Simple Disc Mount — Releases

📡 Simple FTP — Serveur FTP anonyme

Simple FTP est un plugin qui fournit un serveur FTP anonyme sur le port 21. Il permet de transférer des fichiers vers et depuis la PS3 via FTP.

  • Anonyme : aucune authentification requise.
  • Binaire uniquement : transferts binaires pour éviter la corruption.
  • Intégré : inclus dans File Manager.

Lien : Simple FTP — Releases

🎵 Simple CD Info — Informations CD audio

Simple CD Info est un plugin qui restaure l'affichage des noms de pistes, d'album et d'artiste pour les CD audio dans le XMB. Il interroge la base de données gnudb.

  • Recherche automatique : aucune configuration nécessaire.
  • Genre et numéro de disque : remplit correctement les métadonnées.
  • Compatible HEN et CFW.

Lien : Simple CD Info — Releases

🎮 Simple Cheat Menu — Menu de triche en jeu

Simple Cheat Menu est un plugin qui ajoute un menu de triche en jeu. Appuyez brièvement sur le bouton PS pendant n'importe quel jeu pour ouvrir le menu et activer/désactiver des triches en direct.

  • Sans PC : rien à configurer par jeu.
  • Base Artemis : les triches sont tirées de la base Artemis.
  • Onglet Patches : remplacez les textures en jeu (avec Patch Studio).
  • Compteur de stats : affiche le framerate, les fréquences et les températures.

Lien : Simple Cheat Menu — Releases

🔗 Simple Debug Bridge — Débogage à distance

Simple Debug Bridge est un plugin qui permet le débogage et le contrôle à distance de la PS3 via TCP (port 8785). Il est accompagné d'un client Windows (debug-bridge-client.exe).

  • Contrôle à distance : pressez des boutons, lancez et quittez des titres.
  • Proxy HTTP local : http://localhost:8786 pour les outils de déploiement.
  • Logs : consultation des logs de la console.

Lien : Simple Debug Bridge — Releases

06

Outils PC (Windows)

🎨 Theme Studio — Éditeur de thèmes PS3

Theme Studio est un éditeur de thèmes PS3 pour Windows. Il permet de créer des thèmes 2D et des thèmes 3D dynamiques avec des modèles, du mouvement et de l'éclairage — des fonctionnalités que les outils officiels de Sony n'ont jamais supportées.

  • Thèmes 2D : fonds d'écran, icônes, curseurs et sons de menu personnalisés.
  • Thèmes 3D : modèles, mouvement et éclairage.
  • Script PSJS : écriture du mouvement de scène dans le langage de script de Sony.
  • Preview en direct : le script est joué au fur et à mesure de la frappe.
  • Export : un clic pour générer le fichier .p3t ou déployer sur la console via le réseau.

Lien : Theme Studio — Releases

🖼️ RCO Studio — Éditeur de ressources XMB

RCO Studio est un outil moderne pour éditer les fichiers de ressources (RCO) du XMB de la PS3. Il remplace l'ancien workflow RCOmage.

  • Glisser-déposer : plus besoin de taper des chemins ou de nommer des fichiers.
  • Déploiement FTP : envoi des RCO compilés vers dev_blind.
  • Annulation : clic droit pour annuler toutes les modifications d'un RCO en une fois.
  • Panneau de propriétés : affiche les détails du fichier sélectionné.

Lien : RCO Studio — Releases

🖌️ Patch Studio — Remplacement de textures

Patch Studio est un outil PC qui permet de remplacer n'importe quelle texture dans n'importe quel jeu PS3, sans travail spécifique au jeu.

  • Dump : sur l'onglet Patches du menu de triche, Square dumpe les textures du jeu en cours.
  • Édition : Patch Studio télécharge les dumps, les transforme en images éditables.
  • Application : renvoie le patch sur la console et l'applique en jeu.

Lien : Patch Studio — Releases

07

Dépannage

Problèmes courants

ProblèmeCause probableSolution
L'application ne se lance pas HEN non activé (sur PS3HEN). Activez HEN avant de lancer l'application.
Cell Stream : latence élevée Connexion Wi-Fi instable. Utilisez une connexion filaire (Ethernet) entre le PC et la PS3.
Yo! Player : vidéos bloquées à 1 minute Google a modifié son API. Mettez à jour Yo! Player vers la dernière version (le client Apple Vision Pro n'est pas limité).
Simple Disc Mount : ISO non listée L'ISO n'est pas dans le bon dossier. Placez vos ISOs dans /dev_hdd0/PS3ISO/.
Simple Cheat Menu : triches non trouvées Base Artemis manquante ou jeu non supporté. Vérifiez que le jeu est dans la base Artemis.
